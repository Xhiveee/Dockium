# Dockium — дизайн-система

## Направление

**«Приборная панель ночью».** Графитовые поверхности, тёплые светлые чернила и
цвет только там, где он несёт состояние. Интерфейс плотный, но спокойный:
никаких декоративных градиентов, крупных маркетинговых заголовков и цветных
акцентов «для красоты». Главный визуальный приём — тонкие измерительные
линейки, моноширинные числа и вертикальные статус-рейлы у строк экземпляров.

Палитра намеренно не использует привычные синие/фиолетовые акценты: основной
акцент — тёплый светлый (`--accent`), а сигнальные цвета зарезервированы за
статусами (зелёный, жёлтый, красный, голубой).

## Токены

Все значения — в `src/styles/tokens.css`; в компонентах используются только
роли, не приблизительные значения.

### Поверхности и текст

| Токен | Значение | Роль |
|---|---|---|
| `--bg-page` | `#0b0b0c` | фон приложения/сайдбара |
| `--bg-content` | `#0e0e10` | фон рабочей области |
| `--surface-1` | `#131315` | панели, таблицы |
| `--surface-2` | `#18181b` | поля, поповеры, hover-состояния |
| `--surface-3` | `#1e1e21` | активные вкладки, бейджи |
| `--surface-inset` | `#0a0a0b` | инпуты, консоль |
| `--ink` | `#ecebe6` | основной текст |
| `--ink-2` | `#b0aea7` | вторичный текст |
| `--ink-3` | `#8b8982` | подписи, метаданные |
| `--line` | `rgba(255,255,255,.065)` | обычные границы |
| `--line-strong` | `rgba(255,255,255,.12)` | границы контролов |

### Акцент и статусы

| Токен | Значение | Роль |
|---|---|---|
| `--accent` | `#e9e4d7` | primary-кнопки, активный индикатор |
| `--accent-ink` | `#151410` | текст на акценте |
| `--success` | `#6cc59c` | работает / онлайн |
| `--warning` | `#e0b568` | предупреждение / проблема |
| `--danger` | `#e28f8b` | ошибка / удаление |
| `--info` | `#8fb2e2` | запускается / сведения |

Статус — это всегда цвет + текст (точка/бейдж), никогда только цвет.

### Типографика

- UI: **Golos Text** (400/500/600). Числа, ID, пути, логи — **JetBrains Mono**
  (400/500) с `font-variant-numeric: tabular-nums`.
- Размеры: 11 / 12 / 13 / 14 / 15 / 18 / 22 / 28 px; заголовок страницы — 22,
  заголовок диалога — 18, тело — 13–14, подписи — 11.
- Межстрочный: 1.2 для заголовков, 1.45–1.6 для текста.
- Заголовки — 600, отрицательный tracking −0.012…−0.028em.
- Ни в коем случае не использовать ALL CAPS и разрядку для подписей.

### Пространство и форма

- Шкала: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48.
- Радиусы: 4 (мелкие бейджи), 6 (контролы), 9 (кнопки), 12 (панели),
  16 (диалоги), 999 (пилюли).
- Контролы: 28 (sm) / 34 (md) / 40 (lg).
- Тени: только для всплывающих слоёв; панели отделяются границей, не тенью.

### Движение

- `--dur-fast: 120ms`, `--dur-base: 180ms`, `--dur-slow: 280ms`.
- `--ease-out: cubic-bezier(.22,.8,.24,1)`, `--ease-spring: cubic-bezier(.34,1.42,.64,1)`.
- Нажатие кнопки: сжатие 90 ms (минимум) + пружинный возврат ~260 ms через
  Web Animations API; hover/focus — только цвет/граница.
- Появление: fade 180 ms, подъём 6 px, диалог scale .985 → 1.
- Все бесконечные анимации отключаются при `prefers-reduced-motion`; пульсация
  статусов не используется (кроме индикатора набора в терминале).

## Компоненты

Состояния и размеры определены в `src/ui/*`.

- **Button**: variants `primary`, `secondary`, `ghost`, `subtle`, `danger`,
  `dangerSolid`; sizes sm/md/lg; icon-only; loading. Primary — светлый,
  destructive — приглушённый красный.
- **Field/Input/Select/Textarea**: 34 px, вставная поверхность, фокус — мягкое
  кольцо `--accent-soft` + граница `--line-focus`.
- **Switch/Checkbox**: собственные, с явным `aria-checked`, крупная зона
  нажатия; описание всегда под подписью.
- **Tabs**: подчёркивание или пилюля, скользящий индикатор; на узких экранах
  горизонтальная прокрутка/уплотнение.
- **Dialog/Drawer**: портал, блокировка скролла, focus-trap, Escape, возврат
  фокуса; диалог — по центру, drawer — справа (на мобильном во всю ширину).
- **Menu**: портал с фиксированным позиционированием, закрытие по outside
  click/Escape/scroll; пункты с иконками и danger-цветом.
- **Toast**: единый стек снизу справа, максимум 4, дедупликация одинаковых
  сообщений, авто-скрытие 4.5–8 с; при открытом диалоге стек поднимается выше
  футера.
- **Badge/StatusDot**, **Meter**, **Sparkline**, **KeyValue**, **CopyField**,
  **EmptyState**, **Skeleton**, **InlineNotice**, **Panel**, **PageHeader**.
- Иконки — Lucide, 13–17 px, stroke 1.7–1.8; статусы не дублируются иконкой и
  цветом одновременно без текста.

## Анатомия страниц

- **Каркас**: сайдбар 236 px (лого, навигация, статус потока, пользователь),
  рабочая область с центрированным max-width 1560 px. На ≤1024 px сайдбар
  превращается в drawer с верхней панелью.
- **Заголовок страницы**: 22 px название + счётчик/статус, действия справа;
  описание только если оно объясняет неочевидное.
- **Обзор**: один segmented-strip с 4 показателями и измерительной линейкой,
  ниже — список экземпляров и правая колонка (агенты, задачи, входы). Для
  пользователя без админ-прав strip из 3 показателей и одна колонка.
- **Список экземпляров**: поиск, пилюли статусов, фильтр агента; строки-таблица
  с рейлом статуса, метриками, бейджем и действия. На мобильном — карточки.
- **Экземпляр**: back-link, имя + статус + образ, строка фактов (агент, порты,
  запуск, CPU, память, сеть), вкладки «Консоль | Файлы | Расписание |
  Настройки». Консоль — тёмная вставная поверхность с таймстампами и ANSI.
- **Файлы**: хлебные крошки, действия папки/файла/загрузки, строки с размером
  и датой, редактор в drawer, зона drag-and-drop с оверлеем.
- **Агенты/Образы/Пользователи/Безопасность** следуют тем же правилам:
  поверхность-таблица, одна строка = одна сущность, действия в конце.

## Адаптивность

Матрица: 390×844 (телефон), 768×1024 (планшет), 1440×900 (ноутбук),
2560×1249 (широкий монитор), масштаб браузера 75/100/150%.

- ≤1024: drawer-навигация, таблицы становятся карточками, тулбары переносятся.
- ≤760: скрываются второстепенные колонки, заголовки действий остаются
  доступными через меню; формы — в одну колонку.
- ≤520: статистика в 2 колонки, фильтры уплотняются; горизонтальные вкладки
  прокручиваются, ничего не обрезается без возможности прокрутки.

## Доступность

- WCAG 2.2 AA по контрасту: вторичный текст ≥ 4.5:1 на поверхностях.
- Все интерактивные элементы — настоящие `button`/`a`, есть `:focus-visible`
  кольцо, `aria-label` у icon-only, `aria-checked` у switch/checkbox,
  `aria-current` у крошек, роли `progressbar` у метров.
- Диалоги: `role="dialog"`, `aria-modal`, focus-trap, Escape, возврат фокуса.
- Toast: `role="status"`/`alert`, `aria-live`.
- Есть skip-link к контенту.
- Уважается `prefers-reduced-motion`; нет мерцания и автопрокрутки без согласия
  (автопрокрутка консоли отключается при ручном скролле вверх).

## Проверка

Скриншоты: логин, обзор (админ и пользователь), список и карточка экземпляра,
консоль, файлы, расписание, настройки, агенты, образы, пользователи,
безопасность; телефон 390 и широкий 2560. Проверялись создание/запуск/
остановка/перезапуск, консольный ввод, загрузка/редактирование файлов,
создание задачи, токен агента, доступ пользователя, блокировка IP и live-
переподключение.
